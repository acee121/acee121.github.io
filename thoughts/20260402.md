## 一、游戏概述

《第十二层 · The 12th Floor》是一份单文件（`index.html`，约 40KB / 800 余行）的悬疑都市风解谜游戏。玩家在大雨夜来到一栋**「只有 11 层」**的大厦，通过点击在各楼层间跳转、搜索、输入密码来推进剧情，最终寻找一个失踪的人。

游戏最大的两个设计巧思在于：它把**网页本身**变成了谜题的一部分——

- 按键盘的 **F12**，真的会调出游戏内建的「开发者工具」终端，由此进入本不存在的第 12 层；
- 把三段数字碎片按顺序拼成长串，加在网页地址 `#` 之后回车，可打开隐藏链接、进入真结局。

---

## 二、操作与界面速览

左侧为**电梯面板**，点击楼层名即可跳转（部分楼层需满足条件才解锁）；右上角「**线索笔记本**」自动记录你收集到的数字碎片与关键线索，是通关的核心依据，务必常看。

### 核心交互

| 操作 | 说明 |
| --- | --- |
| 鼠标点击 | 点击高亮文字、门牌、按钮、输入框确认等。 |
| `F12` / `Ctrl+Shift+I` | 调出游戏内终端（接管浏览器默认行为）。这是进入真结局的关键。 |
| `Esc` | 关闭终端 / 笔记本 / 弹窗。 |
| 地址栏 `#` 后缀 | 在网页 URL 的 `#` 后追加数字或指令后回车，触发隐藏入口。 |

## 三、关键机制解析

游戏存在两条结局路径，理解下面三个机制就不会卡关。

### 机制 1：三段数字碎片 α / β / γ

散落在不同楼层的三个数字，是开启隐藏结局的「钥匙」。顺序固定为 **α → β → γ**，拼接后即解锁码。

| 片段 | 数值 | 获取方式 |
| --- | --- | --- |
| **α** | `163` | 4F 维修层白板调试地址 `0xA3`（hex）→ 十进制：`10×16 + 3 = 163`。翻工具柜时自动换算记入。 |
| **β** | `0431` | 3F 档案室：档案柜编号的等差规律（见第四节详解），需手动输入验算。 |
| **γ** | `007` | 5F 运转中的机器：铭牌背面直接给出的三位数。 |

> **拼接结果（解锁码）：`1630431007`**　（α=163 + β=0431 + γ=007）

### 机制 2：F12 终端

按 `F12`（或 `Ctrl+Shift+I`）打开伪开发者工具终端，可用命令：

```
> help                显示命令列表
> whoami              查看当前身份（maintainer / guest）
> ls                  列出当前目录（fragments/  maintenance.log  .door  README.txt）
> cat <file>          查看文件，如 cat maintenance.log / cat .door
> unlock <code>       输入解锁码（即拼接后的 1630431007）
> clear               清屏
> exit                关闭控制台
```

**关键一步**：在终端执行 `unlock 1630431007`，验证三段碎片通过后，电梯面板会**真的多出一个从未存在的 F12 选项**（伴随屏幕震动与闪光），之后即可前往第 12 层。

### 机制 3：URL Hash 隐藏入口

在网页地址末尾的 `#` 后追加特定内容再回车，可直接触发隐藏逻辑：

| 地址栏输入 | 效果 |
| --- | --- |
| `...#1630431007` | 拼对数字但未开 F12 时：提示「门不会从外部打开，你需要先进入 F12」。已开 F12 时：直接进真结局。 |
| `...#true` / `...#12` | 同样导向真结局（解锁后直接跳 F12 场景）。 |
| `...#help` · `#f12` · `#console` · `#hint` | 彩蛋提示：「入口不在地址栏里——它在键盘上。试试按 F12。」 |

> ⚠️ 先拼 URL 后开 F12 会被「优雅降级」引导，设计上要求 **F12 与拼接码双线汇合**，这也是两个核心机制的闭环。

## 四、逐层通关攻略

### 1F · 大堂

- **【必做】** 点击「公告栏」——告示角落出现「12 除外。」；点「值班台」听守夜人提示「去 3 楼档案室」。这两个都是早期方向指引。
- **【提示】** 开局 0.9 秒会弹提示「先去 2F 物业办公室」，跟它走最稳。

### 2F · 物业办公室

- **【关键】** 点「抽屉」找到被撕的便签上段，写明 α 的取法（4F 白板 `0xA3` 转十进制）。这是整条链的起点。
- **【可选】** 点「值班表」看到 11-12 夜班工号 A3（涂黑的名字），属背景补充。

### 3F · 档案室

- **【★ 核心谜题】** 这里要自己算。墙上三组档案柜编号，规律是「中间项 = 两头的平均数」（等差数列）。
- **【推理】** 第一组 `410·411·412`、第三组 `450·451·452` 都是连续数；第二组 `430·??·432` 的空位 = (430+432)/2 = 431，补四位即 `0431`。
- **【操作】** 在输入框填 `0431`（四位数）→「验算并提交」。填 `431`（三位）也会被接受，但笔记本统一记录为 0431。
- **【避坑】** 不要习惯性填 `1998`——8F 密码才是 1998 相关，3F 的答案独立为 0431，填 1998 会被提示「看等差规律」。

### 4F · 维修层

- **【关键】** 点「工具柜」：① 得到 8F 密码线索（最后维护日期 = 密码，月日四位）；② α=163 在此自动换算记入笔记本（`0xA3 = 10×16+3`）。同时解锁 8F。
- **【可选】** 点白板「异物 / 通风口」得到便签「入口藏在每天都打开、却从不在意的地方」，是 F12 的隐喻提示。

### 5F · 租户 A

- **【关键】** 点「运转中的机器」：型号 KESTREL-Δ7，铭牌背面三位数 `007` = 片段 γ。这是唯一直接给出、无需计算的碎片。

### 6F · 租户 B

- **【剧情】** 隔间门板刻字：「当数字不再够用时，请按那个不在面板上的键。」——明确暗示 F12 的操作。

### 7F · 走廊

- **【剧情】** 整齐的涂鸦出现 `0xF12`、`if(floor>11){...}`，与「the key is what you already hold」。把 `0xF12` 与键盘 F12 对应起来。

### 8F · 机房

- **【★ 密码】** 输入维护密码。线索在 4F：「系统最后被维护的那天 = 密码，日期月日四位」。日志日期 `1998-11-12` → 密码 `1112`。
- **【答案】** 输 `1112`（或 `19981112` 八位）即可。登录成功后获得「天台钥匙编号 PERMIT-77」，解锁 10F。
- **【提示】** 画面上的 `Last login: 1998-11-12` 就是答案来源，不要被 `●●●●●●` 迷惑。

### 9F · 监控室

- **【可选】** 点 cam12 记录：楼只有 11 层却出现 cam12，「编号 12 不存在于楼层表」——强化「第 12 层」的存在感。
- **【可选】** 点「录像带」确认拼接顺序：α → β → γ。

### 10F · 天台入口

- **【★ 开锁】** 在 8F 已拿到 PERMIT-77。此处输 `77` / `007` / `PERMIT-77` 任一即可开门，通往 11F。

### 11F · 屋顶

- **【★ 分岔点】** 此时出现两个选择——
- **【路线 A】** 点「锈蚀铁门」→ 普通结局 **ENDING A**（到此为止）。游戏会在此把三段碎片 `163 / 0431 / 007` 与拼接码 `1630431007` 明示给你。
- **【路线 B】** 不点铁门，而是按 F12 → 终端 `unlock 1630431007` → 电梯出现 F12 → 真结局 **ENDING B**（推荐二周目走这条）。
